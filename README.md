# Course Recovery System

A Java-based Course Recovery System developed as part of an Object Oriented Development with Java project. The system helps educational institutions manage students who need to recover failed course components through structured recovery plans, eligibility checks, academic performance reporting, and email notifications.

## Features
- User management and authentication
- Course recovery plan creation and tracking
- Eligibility check and enrolment support
- Academic performance reporting
- Email notifications
- GUI-based interaction

## Technologies Used
- Java
- Object-Oriented Programming
- Java GUI
- File handling
- Text and binary file storage
